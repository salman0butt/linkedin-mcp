# LinkedIn MCP

Production-grade Model Context Protocol server for LinkedIn workflows.

## Status

M00 — Foundation + autonomous development control plane is active. No LinkedIn account access is implemented yet.

## Product direction

The project is official-API-first and keeps provider provenance explicit. Future capabilities include identity/authentication, post publishing, media, comments/replies/reactions, post discovery, job discovery/intelligence, long-form article workflows, scheduling, analytics, company pages, networking, messaging, and hosted multi-account operation.

## Engineering model

Git/GitHub is durable execution truth. CI/tests provide objective verification. Superpowers provides the engineering workflow. Fresh sessions recover state from the repository instead of relying on chat memory.
